# 自動埋め込みのテスト

対応サービスの URL を **単独の行** に貼り付けるだけで、自動的に埋め込みに変換されます。
（import やコンポーネントの記述は不要です）

# h1
h1です。

## h2
h2です。

### h3
h3です。

**太字です**

*イタリックです*

## 通常のリンク

文章中のリンク（[このように](https://example.com) テキストを伴うもの）や、
段落内に他の文章と混在する URL https://example.com は変換されません。
